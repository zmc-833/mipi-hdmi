## 三条必读约定（摘要）

1. **坐标不要自己写计数器** —— 用 top 里的 `S_pix_x[10:0]` / `S_pix_y[9:0]` / `S_frame_done`。
2. **颜色判定必须转 YCbCr** —— 系数抄郭的 `chroma_denoise.v`（Y=77/150/29、Cb=−43/−85/+128、Cr=+128/−107/−21，分母 256）。
3. **显示掩膜不要改 `hdmi_mixer.v`** —— 只改 `S_mask_hit` 的驱动源，优先级已在 top 排好。
