## 二、仲裁层接法

你的 `design_top_wrapper.v` 里第 1029-1035 行原本给掩膜留了桩：

```verilog
assign S_mask_hit = 1'b0;     // 你预留的占位
```

我替换成了真实接入：

```verilog
wire S_det_mask_r, S_det_mask_g, S_det_mask_b;

detect_color_mask #(
    .IMG_WIDTH(1280), .IMG_HEIGHT(720), .PIPE_DELAY(0), .PIX_DLY(2)
) u_detect_color_mask (
    .clk(S_hdmi_pixel_clk), .rst_n(S_hdmi_rst_n),
    .I_de(S_hdmi_de), .I_vsync(S_hdmi_vsync), .I_hsync(S_hdmi_hsync),
    .I_user(S_hdmi_user), .I_last(S_hdmi_last), .I_rgb(S_video_sat),
    .I_pix_x(S_pix_x_2d), .I_pix_y(S_pix_y_2d),
    .I_color_sel(2'd0), .O_mask(S_mask_hit), ...
);

assign S_mask_color = 24'h00_FF_00;   // 掩膜输出纯绿

// 叠加优先级：坐标 OSD > 画框/准星 > 检测掩膜
assign S_ovl_hit   = S_mask_hit | S_box_hit | S_coord_hit;
assign S_ovl_color = S_coord_hit ? S_coord_color
                   : (S_box_hit  ? S_box_color : S_mask_color);
```

**优先级严格按你原来定的**：坐标 OSD 最高，其次是你的画框/准星，掩膜垫底。  
自检 ⑥ 验证了这一点（框压在绿色掩膜上层，框没被染绿）。

## 六、要同步给你的两个坑（重要，你也会踩）

### 坑 1：TD 加源文件**必须走 GUI**

**手工改 `.al` 完全无效** —— TD 打开工程时会按内部状态回写 `.al`，  
把外部加的条目抹掉。我实测踩了三次：

```
21:01 回写 → 剩 62 条
21:15 回写 → 新增条目归零
21:19 回写 → 剩 63 条
```

**正确做法**：

```
Source → Add Source...  →  Add Source Wizard
  → Design files  →  Next
  → 勾 Verilog   →  Next
  → Add Files    →  选 .v 文件
  → Finish       →  File → Save Project
```

**注意入口在菜单栏的 `Source`，不在 `Project` 菜单里。**

**验证添加成功**：看 Hierarchy 面板左下角 **`Compile Order`** 标签页 ——  
那里才是完整文件清单（Hierarchy 树只显示模块层次，看不到文件）。

走 GUI 加完后 `.al` 稳定 67 条，不再被回写。
