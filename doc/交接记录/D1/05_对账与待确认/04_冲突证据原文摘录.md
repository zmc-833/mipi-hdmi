## 证据 1：YCbCr 系数一致 ✅

**`user_source/hdl_source/common_base/common_defs.vh` 第 40~54 行**

```verilog
`define YCBCR_KR         18'sd77
`define YCBCR_KG         18'sd150
`define YCBCR_KB         18'sd29

`define YCBCR_CB_KR     -18'sd43
`define YCBCR_CB_KG     -18'sd85
`define YCBCR_CB_KB      18'sd128

`define YCBCR_CR_KR      18'sd128
`define YCBCR_CR_KG     -18'sd107
`define YCBCR_CR_KB     -18'sd21

`define YCBCR_ROUND      18'sd128
`define YCBCR_SHIFT      8
`define YCBCR_BIAS       10'sd128
```

对照 `user_source/hdl_source/chroma_denoise.v` 第 97~103 行（郭的原实现）：

```verilog
wire signed [17:0] y_calc  =  18'sd77  * r_ext +  18'sd150 * g_ext +  18'sd29  * b_ext;
wire signed [17:0] cb_calc = -18'sd43  * r_ext + -18'sd85  * g_ext +  18'sd128 * b_ext;
wire signed [17:0] cr_calc =  18'sd128 * r_ext + -18'sd107 * g_ext + -18'sd21  * b_ext;
wire signed [9:0]  y_pre   =        (y_calc  + 18'sd128) >>> 8;
wire signed [9:0]  cb_pre  = ((cb_calc + 18'sd128) >>> 8) + 10'sd128;
wire signed [9:0]  cr_pre  = ((cr_calc + 18'sd128) >>> 8) + 10'sd128;
```

**逐字相同，包括 ROUND/BIAS 两个容易漏的偏置。结论：一致。**

## 证据 7：消隐期行为表述不同 ⚠️

**盘点清单 B5**（他的）："消隐期行为：de 无效时坐标保持（不动）"

**我的 `rtl/pix_coord_gen.v` 实际**（交接文档第 115 行）：

```
vsync 上升沿（场消隐期，de 恒 0）：x ← 0, y ← 0        ← 唯一归零点
de 有效 & last=1（行末像素）：     x ← 0, y ← y+1
de 有效 & last=0：                 x ← x+1
```

**我为什么这么写**（交接文档第 134~139 行）：

> `hdmi_mixer` 第 327~345 行那份计数器用"`user` 优先清零"写法，位级审计证明有两个副作用：
> ① **首行（r=0）整行 `S_x` 比真实列号小 1**；② 帧首像素采到上一帧残留 `S_y=720`。
> 我的 `pix_coord_gen` 改用**场消隐期归零**，**无这两个偏移**。

⇒ 表述需要统一成 vsync 归零，否则以后被误改。
