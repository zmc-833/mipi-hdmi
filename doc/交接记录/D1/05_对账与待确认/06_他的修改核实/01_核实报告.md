## 二、我做的独立仿真验证（重点）

### 验证对象：`detect_color_mask` 的坐标延时对齐（7a 那件事）

他在 7a 里说："我在模块输入端补一级寄存器凑满 3 拍"。
**实际上他没这么土** —— 他做成了**参数化方案**：

```verilog
parameter integer PIX_DLY = 2,   // 外部坐标已延的拍数
// 抽头 = 1 - PIX_DLY：
//   PIX_DLY = 2 → 输出级接 I_pix_x 本身（外部已延 2，内部再 1 → 共 3）
//   PIX_DLY = 1 → 输出级接 pxc[0]
//   PIX_DLY = 0 → 输出级接 pxc[1]
```

### 我写的独立 TB（`tb_pix_dly_check.v`，不依赖他的 tb）

- 模拟真实集成：`S_pix_x` → 延 2 拍 → `S_pix_x_2d` → 模块 `I_pix_x`
- `S_pix_x` 每拍严格 +1（永不重复），便于反推延时
- 判据：**`O_de=1` 当拍，`O_pix_x` 是否等于「3 拍前的 `S_pix_x`」**
  （掩膜路径固定 3 拍，RTL: C0→P1→P2→P3→O_mask）

### 实测结果（iverilog 12.0，本机实跑）

```
===== PIX_DLY=0 （接 S_pix_x）     受检 33 拍，错位 0 拍 → PASS =====
===== PIX_DLY=1 （接 S_pix_x_1d）  受检 33 拍，错位 0 拍 → PASS =====
===== PIX_DLY=2 （接 S_pix_x_2d）  受检 33 拍，错位 0 拍 → PASS =====
```

**三种取值全部 PASS。** 他的参数化改造正确，坐标与掩膜路径严格同拍。

> ⚠️ 过程说明：我第一版 TB 没模拟 `_2d` 的 2 拍前置延时，测出"差 2 拍"，那是 **TB 的错**、
> 不是设计的错。修正 TB 后 3 种配置全过。这条记下来是因为**同一个坑也会坑实际集成的人**。
